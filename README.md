# 🐶 개 치료 — 구출된 개들을 치료하기

**반려견 입양을 장려하는 3D 교육용 콘텐츠 (Unity)**

플레이어는 **개들의 과거 아픔을 볼 수 있는 수의사**가 됩니다. 근처 강아지 공장에서 구조된 개들을 진찰해 각자의 아픔을 파악하고, 치료합니다.

> ⚠️ 원본 소스코드는 유실되어 보고서와 시연 영상만 남겨둡니다.

## 기획 의도
펫숍 유통 과정에서 개들이 겪는 현실을 세 마리의 개를 통해 보여줍니다.

| 개 | 증상 | 원인 |
|---|---|---|
| 1️⃣ 인기 품종의 갓 태어난 소형견 | 슬개골 탈구, 백내장 같은 안구 질환, 단두종 증후군 | 잦은 근친 교배로 인한 유전병 |
| 2️⃣ 지쳐서 누워 있는 개 | 계속된 임신과 출산 | 무분별하고 무책임한 번식 |
| 3️⃣ 입질이 심하고 계속 짖는 개 | 사람에 대한 불신 | 열악한 환경과 학대 |

이를 통해 다음을 전하고자 했습니다.
1. 펫숍 유통 과정에서 일어나는 **여러 이면** 알리기
2. 강아지를 분양받을 때 가져야 할 **책임감**
3. 부견·모견의 **건강 상태**를 확인하고 분양받기를 권장

## 플레이 방법
트레이에 놓인 아이템 중 필요한 것을 골라 개에게 가져다주는 방식으로 치료합니다.

1. **진찰하기** 버튼을 누르면 개의 과거 장면으로 이동합니다.
2. **클립보드**가 개의 상태와 치료 방법을 알려줍니다.
3. 트레이의 **아이템**을 클릭한 뒤 개를 클릭하면, 아이템이 개에게 날아가 치료가 진행됩니다.
4. 치료를 마치면 **다음 개 진찰** 버튼이 활성화됩니다.

## 구현

### 씬 구성 (총 7개)
`first`(첫 대사) → `firstdog`(첫 번째 개의 아픔) → `hospital`(첫 번째 개의 병원) → `hospital2`(두 번째 개의 병원) → `second`(두 번째 개의 아픔) → `hospital3`(세 번째 개의 병원) → `third`(세 번째 개의 아픔)

### 치료하기 (아이템을 개에게 가져다주는 과정)
- **오브젝트 선택**: 레이(Ray)를 쏘고, 오브젝트의 태그로 어떤 아이템인지 구별합니다.
- **플레이어 앞으로 이동**: 빈 오브젝트를 만들어 두고 그 위치로 아이템(클립보드 포함)을 옮깁니다.
- **개에게 던지기**: 두 오브젝트 사이의 벡터를 정규화해 방향 벡터를 만들고 `AddForce`를 줍니다. Rigidbody의 `UseGravity`는 `false`로 설정했습니다.
- **상태 변경**: 예를 들어 들고 있던 아이템의 태그가 `towel`이면 개 상태 스크립트의 `hasTowel`을 `true`로 바꿉니다.
- **아이템 사라짐**: `OnTriggerEnter`로 충돌을 감지해 아이템을 없앱니다.

### 개 상태 스크립트
'다음 개 진찰' 버튼을 활성화하기 위한 조건 변수들, 개들의 위치, 개들의 Animator를 관리합니다.

### 과거의 아픔 장면
공통으로 **Post-processing**(Depth of Field, Vignette, Grain)을 적용했습니다.
1. **첫 번째 개**: `Update()`에서 `LookAt`으로 모견을 바라보고, 코루틴으로 카메라가 `(0, -1, 1)` 방향으로 빠집니다.
2. **두 번째 개**: 스폰 포인트 13개에 `Instantiate`로 프리팹을 배치합니다. `LookRotation`으로 프리팹의 z축이 카메라를 향하게 한 뒤, 그 방향으로 `AddForce`를 줍니다.
3. **세 번째 개**: `Mathf.Sin`으로 hand 오브젝트가 가로로 누운 8자 모양으로 움직이게 했습니다.

### 버튼
빈 게임 오브젝트에 씬 로드 스크립트를 붙이고, 버튼의 `onClick`에 그 오브젝트를 연결해 씬을 로드하는 함수를 호출합니다.

## 사용 기술
- Unity, C#
- Raycast와 Tag, Rigidbody `AddForce`, `OnTriggerEnter`
- Coroutine, `Instantiate`, `LookAt` / `LookRotation`
- Post-processing (Depth of Field, Vignette, Grain)
- Canvas UI 버튼 이벤트, `SceneManager`

## 느낀 점
처음에는 강아지 공장에 잠입한 동물 복지 직원의 스파이물을 만들고 싶었습니다. 그런데 그렇게 하면 '애완동물 가게에서 사지 말고 입양하자'는 주제 의식이 잘 드러나지 않을 것 같았습니다. 그래서 플레이어를 수의사로 바꿔 동물 한 마리 한 마리의 아픔을 설명할 시간을 만들었고, 수의사가 동물을 터치하면 과거의 아픔을 볼 수 있다는 컨셉을 더했더니 전하고 싶었던 의도에 맞게 이야기가 잘 구성되었습니다.

또 이번 프로젝트를 하면서 유니티 실력을 키우고 싶어서, 수업 시간에 배운 내용을 최대한 많이 활용해보려고 했습니다. 스크립트 간 데이터 전달, 캔버스 버튼의 onClick 이벤트, Ray와 Tag 활용 같은 기능을 직접 써볼 수 있었고, 가상현실 수업에서 배운 기능을 복습하는 시간도 되었습니다.
